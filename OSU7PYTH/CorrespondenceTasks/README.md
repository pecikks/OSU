# Correspondence Tasks

This folder contains Python assignments for school correspondence tasks. Each file is a separate small program focused on basic Python syntax, functions, classes, inheritance, and simple data processing.

## Files

| File | Summary |
| --- | --- |
| `svrlansky1.py` | Reads 10 numbers from the user, calculates their sum, average, minimum, maximum, and counts how many are even or odd. |
| `svrlansky2.py` | Defines a `triangle(a, b, c)` function that checks whether three side lengths can form a valid triangle using the triangle inequality. Includes several test cases. |
| `svrlansky3.py` | Generates a list of 10 random numbers from 1 to 100, prints the original list, sorts it, and prints the sorted result. |
| `svrlansky4.py` | Implements a simple Caesar cipher for lowercase letters. The user enters text and a shift value, and the program prints the encoded result. |
| `svrlansky5.py` | Defines a `Kruznice` class for a circle, with methods for calculating circumference and area. Includes example circles and printed results. |
| `svrlansky6.py` | Defines classes for computer components: `Processor`, `Memory`, `HardDisk`, and `Computer`. The program creates a sample computer and prints its specifications. |
| `svrlansky7.py` | Defines customer-related classes including `Zakaznik`, `Firma`, `Osoba`, and `RodneCislo`. It works with Czech birth numbers, extracts birth date and gender, and checks validity. |
| `svrlansky8.py` | Demonstrates multiple inheritance with classes for an electrical appliance, light source, heat source, and a `Zarovka` light bulb. Includes example value changes. |

## Notes

The programs are written as standalone scripts and can be run individually with Python:

```bash
python svrlansky1.py
```

Some scripts ask for user input, while others run built-in examples directly.
