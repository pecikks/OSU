This repository contains my correspondence assignments for the 7ALG1 course, along with Java programming exercises and projects focused on the basics of object-oriented programming.

The main goal is to practice writing simple Java programs using IntelliJ IDEA and to understand core concepts such as classes, objects, references, variables, constants, methods, constructors, and method overloading.

The repository also covers basic programming structures like conditions, loops, arithmetic and logical expressions, data types, type conversions, arrays, and an introduction to more advanced data structures such as linked lists.
